<details>
<summary><b>How Korivash Station is wired</b> (architecture diagram)</summary>

<br />

```mermaid
flowchart LR
    Owner(["📱 Owner<br/>Discord on phone"]) <-->|requests / approvals| Relay["💬 Discord relay bot"]
    Relay <--> Lead
    Hub["🖥️ Web hub<br/>agent.korivash.com"] <--> Lead

    subgraph Station["Korivash Station - one Windows VPS"]
        Lead["🧠 Lead agent (Claude)<br/>plans, reviews, deploys"]
        Lead -->|build tasks| Luna["🌙 Luna (Codex)<br/>builds and routine reviews"]
        Lead -->|research and art| Gem["🎨 Gemini<br/>images and research"]
        Lead --> Guardian["🛡️ Guardian<br/>health checks, restarts, boot report"]
        Memory[("📚 Shared memory<br/>souls, tasks, permissions, DB")]
        Lead <--> Memory
        Luna <--> Memory
        Gem <--> Memory
    end

    Lead -->|pm2 + IIS| Miko["🎧 Miko Radio<br/>10 shard clusters"]
    Lead -->|pm2 + IIS| Sites["🌐 Websites and APIs"]
    Lead -->|builds| Rhythm["🎮 Miko Rhythm (Steam)"]
    Guardian -.->|watches| Miko
    Guardian -.->|watches| Sites
```

Every agent has a `soul.md` (who it is), `memory.md` (what it learned), `task.md` (what it is doing) and `permissions.md` (what it may touch). The lead never does silent work: every task is visible in the hub and reported back to Discord. The public console lives in [agent-console-public](https://github.com/Korivash/agent-console-public).

</details>
