### 🎵 Miko Radio

A Discord music bot serving **19,000+ servers** across 10 sharded clusters. 100% free — no votes or payment required for core functionality. Built for reliability and a clean UX.

Multi-source playback (Spotify, Apple Music, Deezer, YouTube Music), 24/7 streaming, audio filters, custom playlists, Last.fm scrobbling, and autoplay recommendations.
